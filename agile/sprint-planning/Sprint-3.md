# Sprint 3: 命令列參數解析與整合測試

## Sprint 目標
增強 CLI 使用者體驗與測試覆蓋率，包含：
- 實作命令列參數解析 (--model, --api-key, --config)
- 建立整合測試
- 增加重試機制測試
- 優化錯誤處理與日誌記錄

## Sprint 週期
- 開始日期: 2026-11-06
- 結束日期: 2026-11-07
- 持續時間: 1 天

## User Stories

### US-013: 實作命令列參數解析
**優先級**: P1 (重要)
**描述**: 增強 CLI 支援命令列參數，如 --model, --api-key, --config。
**驗收標準**:
- [ ] 支援 --help 顯示說明
- [ ] 支援 --model 自訂模型名稱
- [ ] 支援 --api-key 設定 API 密鑰
- [ ] 支援 --config 載入設定檔路徑
- [ ] 支援 --base-url 設定 API 端點

### 整合測試: Agent End-to-End 測試
**優先級**: P1 (重要)
**描述**: 建立端點到端點測試驗證 Agent Loop 與 Mock API 的互動。
**驗收標準**:
- [ ] 測試 Agent Loop 執行無工具任務
- [ ] 測試 Agent Loop 執行有工具任務 (Mock)
- [ ] 測試錯誤處理與重試機制

### 重試機制測試
**優先級**: P1 (重要)
**描述**: 建立針對 RetryPolicy 的專門單元測試。
**驗收標準**:
- [ ] 測試成功時不重試
- [ ] 測試失敗時重試 (指數退避)
- [ ] 測試達到最大重試次數後拋出例外
