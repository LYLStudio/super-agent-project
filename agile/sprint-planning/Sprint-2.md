# Sprint 2: 錯誤處理、重試機制與新增工具

## Sprint 目標
強化系統的健壯性與擴展性，包含：
- 升級 NuGet 套件修復安全性漏洞
- 實作 OpenAI API 請求重試與錯誤處理
- 新增檔案搜尋與 Git 操作工具
- 實作對話會話持續儲存
- 增加整合測試

## Sprint 週期
- 開始日期: 2026-11-04
- 結束日期: 2026-11-05
- 持續時間: 1 天

## User Stories

### US-007: 實作對話會話持續儲存
**優先級**: P1 (重要)
**描述**: 實作對話歷史持續儲存，支援多次對話會話回復。
**驗收標準**:
- [ ] 會話歷史可儲存到 JSON 檔案
- [ ] 支援載入歷史會話繼續對話
- [ ] 會話檔案包含時間戳與元資料

### US-008: 實作 Agent Loop 錯誤處理與重試機制
**優先級**: P1 (重要)
**描述**: 增強 API 請求與工具執行的錯誤處理，支援自動重試。
**驗收標準**:
- [ ] API 請求失敗時自動重試 (最多 3 次)
- [ ] 工具執行錯誤不會中斷 Agent Loop
- [ ] 重試間隔採用指數退避策略

### US-009: 增加檔案搜尋工具
**優先級**: P1 (重要)
**描述**: 新增支援在檔案系統中搜尋檔案內容的工具。
**驗收標準**:
- [ ] FileSearchTool 支援關鍵字搜尋
- [ ] 支援檔案路徑篩選
- [ ] 回傳搜尋結果與匹配行號

### US-010: 增加 Git 操作工具
**優先級**: P1 (重要)
**描述**: 新增支援 Git 版本控制操作的工具。
**驗收標準**:
- [ ] GitTool 支援 git status, git log, git diff
- [ ] 支援 git add, git commit
- [ ] 回傳命令輸出結果

### US-013: 實作命令列參數解析
**優先級**: P1 (重要)
**描述**: 增強 CLI 支援命令列參數，如 --model, --api-key, --config。
**驗收標準**:
- [ ] 支援 --help 顯示說明
- [ ] 支援 --model 自訂模型
- [ ] 支援 --api-key 設定密鑰
- [ ] 支援 --config 載入設定檔
