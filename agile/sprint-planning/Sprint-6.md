# Sprint 6: 工具路由與錯誤分類 (Tool Routing & Error Classification)

## Sprint 目標
優化工具路由機制與錯誤分類，包含：
- 工具路由系統：根據任務類型自動選擇適當的工具
- 錯誤分類：將錯誤分類為網路錯誤、API 錯誤、工具錯誤、設定錯誤
- 改善錯誤報告：提供更詳細的錯誤上下文與建議
- 新增錯誤重試策略：根據錯誤類型應用不同的重試策略
- 改善 Agent Loop 錯誤恢復機制
- 新增單元測試覆蓋錯誤分類與工具路由

## Sprint 週期
- 開始日期: 2026-11-09
- 結束日期: 2026-11-10
- 持續時間: 1 天

## User Stories

### US-021: 工具路由系統
**優先級**: P1 (重要)
**描述**: 建立工具路由系統，根據任務類型自動選擇最適合的工具。
**驗收標準**:
- [ ] 支援根據任務關鍵字自動建議工具
- [ ] 支援工具優先級設定
- [ ] 支援工具不可用時的降級機制
- [ ] 新增 ToolRouter 類別與介面

### US-022: 錯誤分類系統
**優先級**: P1 (重要)
**描述**: 將錯誤分類為網路錯誤、API 錯誤、工具錯誤、設定錯誤。
**驗收標準**:
- [ ] 定義 ErrorClassification 列舉
- [ ] 新增 ErrorClassifier 類別
- [ ] 錯誤訊息包含分類資訊
- [ ] 支援錯誤統計與追蹤

### US-023: 錯誤重試策略
**優先級**: P1 (重要)
**描述**: 根據錯誤類型應用不同的重試策略。
**驗收標準**:
- [ ] 網路錯誤：指數退避重試
- [ ] API 錯誤：固定間隔重試
- [ ] 工具錯誤：不重試
- [ ] 設定錯誤：不重試，直接報告

### US-024: Agent Loop 錯誤恢復
**優先級**: P1 (重要)
**描述**: 改善 Agent Loop 的錯誤恢復機制。
**驗收標準]:
- [ ] 錯誤後可繼續執行
- [ ] 支援跳過失敗的工具
- [ ] 錯誤統計與摘要
- [ ] 支援部分失敗但整體成功
