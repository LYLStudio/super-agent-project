# 需求規格文件

## 1. 功能需求

### FR-001: 對話能力
Agent 應能理解自然語言指令並生成合適回應。

### FR-002: Agent Loop 能力
Agent 應具備有序的思考、規劃、執行與觀察迴圈，可以自主決定需要哪些工具。

### FR-003: 工具使用
Agent 應能選擇並執行適當的工具來完成任務，包括：
- 代碼撰寫工具
- 代碼讀取工具  
- Shell 執行工具

### FR-004: 模型自訂
支援透過環境變數自訂 API 端點、密鑰與模型名稱。

### FR-005: CLI 介面
支援命令列互動，包含 exit、help 命令。

## 2. 非功能需求

### NFR-001: 效能
- Agent Loop 每次迭代應在 5 秒內完成
- API 請求應支援超時設定

### NFR-002: 可靠性
- 工具執行錯誤應被優雅處理
- 支援最大迭代次數限制防止無限循環

### NFR-003: 維護性
- 程式碼應有完整的 XML 註解
- 遵循 .NET 命名慣例

## 3. 技術需求

### TR-001: 平台
- .NET 10 SDK

### TR-002: 相容性
- 支援 OpenAI 相容 API 規格 (相容 OpenAI API 端點)

### TR-003: 模型
- 預設模型: qwen3-coder:30b
- 支援自訂模型名稱
