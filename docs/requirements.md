# 需求規格文件

## 1. 功能需求

### FR-001: 對話能力
Agent 應能理解自然語言指令並生成合適回應。

### FR-002: Agent Loop 能力
Agent 應具備有序的思考、規劃、執行與觀察迴圈，可以自主決定需要哪些工具。

### FR-003: 工具使用
Agent 應能選擇並執行適當的工具來完成任務，包括：
- 代碼撰寫工具
- 代碼讀取工具  
- Shell 執行工具

### FR-004: 模型自訂
支援透過環境變數自訂 API 端點、密鑰與模型名稱。

### FR-005: CLI 介面
支援命令列互動，包含 exit、help 命令。

## 2. 非功能需求

### NFR-001: 效能
- Agent API 請求須有可設定的逾時，預設 120 秒
- 預設每個任務最多 20 次 Agent 迭代、每次回應最多 8000 tokens
- 對話上下文軟預算預設為 32000 字元，優先保留 system prompt 與最新完整回合，省略較早回合並裁切較長的非使用者訊息
- 搜尋、資料庫查詢、日誌與效能指標須設資源上限，避免輸出或記憶體無界成長
- 啟動 CLI 時，非互動模式不應額外發出模型清單請求

### NFR-004: 使用體驗
- 思考串流預設關閉，使用者可透過設定主動開啟
- Agent 工具呼叫歷史須符合 OpenAI 相容 API 的 assistant/tool 訊息格式
- 搜尋及資料庫結果超過上限時，須明確提示結果已截斷

### NFR-002: 可靠性
- 工具執行錯誤應被優雅處理
- 支援最大迭代次數限制防止無限循環

### NFR-003: 維護性
- 程式碼應有完整的 XML 註解
- 遵循 .NET 命名慣例

## 3. 技術需求

### TR-001: 平台
- .NET 10 SDK

### TR-002: 相容性
- 支援 OpenAI 相容 API 規格 (相容 OpenAI API 端點)

### TR-003: 模型
- 預設模型: qwen3-coder:30b
- 支援自訂模型名稱
